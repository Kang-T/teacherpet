# 🐥 티처펫 (TeacherPet)

선생님 컴퓨터 바탕화면에서 함께 자라는 작은 친구.
학급 아이들과 함께 이름을 짓고, 먹이를 주고, 알에서 어른이 될 때까지 키워 보세요.

## 무엇을 하나요

| 기능 | 설명 |
|---|---|
| 🐥🐹🐢🐰 **4종 친구** | 병아리·햄스터·거북이·토끼. 동물마다 행동이 달라요 (햄스터는 쳇바퀴, 거북이는 등껍질 숨기, 토끼는 깡총, 병아리는 모이 쪼기). 최대 3마리. |
| 🥚 **다마고치식 성장** | 알 → 아기 → 어른. 먹이는 30분에 한 번만. 매일 조금씩 돌봐야 자라요 — 책임감과 기다림을 배우는 장치예요. |
| ⏱ **수업 타이머 + 집중 모드** | 수업 40분 / 쉬는 시간 10분(변경 가능). 수업 중엔 펫이 조용히 앉아 있고, 쉬는 시간이 되면 신나게 뛰어요. |
| 🎲 **랜덤 뽑기** | 이름 목록에서 발표자·모둠 뽑기. "뽑힌 사람 제외" 지원. |
| ✅ **오늘 할 일** | 간단한 체크리스트. 하나 끝내면 펫이 박수. |
| 💬 **선생님 챙기기** | 가끔 "물 한 잔 드셨어요?", "기지개 한 번!" 하고 말을 걸어요 (끌 수 있어요). |
| 🖥 **전자칠판** | 설정에서 크기를 "크게"로. 아이들이 터치해도 반응해요. |

인터넷 연결이나 로그인이 필요 없고, 개인정보를 수집하지 않습니다. 모든 데이터는 이 컴퓨터 안에만 저장됩니다.

## 설치 (윈도우)

1. [최신 릴리즈](https://github.com/Kang-T/teacherpet/releases/latest) 페이지에서 `TeacherPet-x.x.x-win-x64.exe`를 내려받습니다.
2. 실행하면 **"Windows의 PC 보호"** 파란 창이 뜰 수 있습니다. (아직 유료 코드 서명을 하지 않아서 뜨는 것이며, 바이러스가 아닙니다.)
   - 창 안의 **"추가 정보"** 글자를 클릭 → **"실행"** 버튼 클릭
3. 설치가 끝나면 바탕화면과 시작 메뉴에 **티처펫** 아이콘이 생깁니다.
4. 처음 켜면 입양 창이 열립니다. 친구를 하나 고르면 알이 도착해요.

작업 표시줄 오른쪽 아래 **트레이 아이콘(병아리)** 을 클릭하면 메뉴가 열립니다. 종료도 여기서 합니다.

## 사용법

- 펫 **클릭** = 쓰다듬기 · **더블클릭** = 메뉴 · **드래그** = 옮기기 · `Esc` = 메뉴 닫기
- 트레이 아이콘 오른쪽 클릭 → 수업 시작 / 쉬는 시간 / 크기 / 자동 실행 / 종료

## 개발

```bash
npm install
npm start          # 실행
npm run icon       # 아이콘 다시 만들기
node scripts/preview-sheet.js   # 캐릭터 시트 미리보기 → build/sheet.png
```

릴리즈는 태그를 올리면 GitHub Actions가 윈도우·맥 설치 파일을 만들어 자동으로 게시합니다. 자세한 절차: [docs/릴리즈_방법.md](docs/릴리즈_방법.md)
