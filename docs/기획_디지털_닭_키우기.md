# 티처펫 — 디지털 닭 키우기 기획서

> 2026-09-16 작성. 조사 4건(닭 행동학 / 사육 실무 / 육성 게임 메커니즘 / 현재 코드 구조)을 종합한 설계안.
> **이 문서는 승인용입니다.** 각 항목의 ✅는 제 제안이고, 선생님이 바꾸실 것만 말씀해 주시면 됩니다.

## 0. 한 줄 정의

**교실에서 실제로는 키울 수 없는 닭의 한살이를, 실제 수치 그대로 압축해 바탕화면에서 함께 키우는 프로그램.**

## 1. 교육적 정당화 — 왜 "디지털"이어야 하는가

조사에서 나온 근거입니다. 이 다섯 줄이 이 프로젝트의 존재 이유입니다.

1. **닭의 한살이는 최소 23주**(부화 21일 + 초산 20주)다. 한 학기에 물리적으로 안 들어간다.
   → 그래서 3학년 과학 [4과04-01]은 배추흰나비로 관찰하고, **닭은 조사 대상([4과04-03])에 머문다.**
2. **첫 주 35℃를 24시간 유지 + 매일 청소 + 48시간 무급수 금지.** 주말이 있는 학교는 구조적으로 충족 불가.
3. 2022년 서울의 한 초등학교에서 **토끼 39마리를 산에 유기**(5마리 폐사)했다. **그 학교는 동물복지 시범학교였다.**
   원인으로 지목된 것: 교사 인사이동으로 인한 책임 단절, 주말·방학 돌봄 공백, 개체 수 통제 실패.
4. 전문가 결론(서울대 수의대 천명선 교수): **"동물을 직접 만지고 기르지 않아도 모형과 영상으로 동물복지 의식과 생명존중 의식을 충분히 기를 수 있다."**
5. 그런데 **아이들이 배워야 할 인과관계(온도·물·청소·질병·비용)는 오히려 수치로 시뮬레이션할 때 더 잘 드러난다.**
   실물 사육에서는 "죽었다"만 남고 왜 죽었는지는 남지 않는다.

## 2. 조사에서 나온 "그대로 쓸 수 있는" 핵심 사실

### 2-1. 닭이 실제로 하는 행동 (활동 시간 배분)

| 행동 | 깨어 있는 시간 중 | 비고 |
|---|---|---|
| **땅 쪼기** | **60%** | |
| **땅 긁기** | **34%** | 먹이통이 가득해도 긁는다(逆무임승차) |
| 깃털 다듬기 | 12~13% | 짧게-자주 = 스트레스 신호 |
| 모래 목욕 | **이틀에 1회, 평균 27분** | 전염됨. 붐비면 시간이 짧아짐 |

> **가장 큰 발견**: 지금 티처펫의 기본 idle은 "가만히 서 있기"인데, **실제 닭의 기본값은 땅 긁기**다. 이것 하나만 바꿔도 "닭다움"의 90%가 해결된다.

**땅 긁기의 정확한 동작** (이 후진 스텝이 빠지면 닭처럼 안 보인다)
```
지면 응시 → 앞을 한 번 쫀다 → 쫀 자리로 한 걸음 올라선다
→ 오른발로 뒤로 긁기 → 왼발로 긁기 (2~3회 교대)
→ 한두 걸음 뒤로 물러선다  ← 파낸 곳이 발밑에 가려지므로
→ 고개를 45° 기울여 한쪽 눈으로 확인
```
- 첫 긁기는 **대개 오른발**. (오른발–오른눈 조합이 먹이 식별에 유리)
- **부화 당일부터** 나오는 선천 행동.

**머리 까딱임(head bobbing)** — 닭의 눈은 눈구멍에 고정되어 거의 안 움직인다. 그래서 **머리를 공간의 한 점에 정지시킨 채 몸만 전진하고, 한계에 오면 머리를 탄도처럼 앞으로 내던진다.** 등속 이동이 아니라 **정지 → 순간이동 → 정지**. 현재 코드는 머리를 부드럽게 보간하고 있어 고칠 부분.

### 2-2. 병아리 온도 — 숫자를 화면에 안 쓰고 가르치는 법

| 주령 | 필요 온도 |
|---|---|
| 1주 | **35℃** |
| 2주 | 32℃ |
| 3주 | 29℃ |
| 4주 | 27℃ |
| 5주 | 24℃ |
| 6주 | 21℃ (보온 종료) |

**병아리 배치가 곧 온도계다** — 이게 이 기획의 백미입니다.

| 배치 | 소리 | 뜻 |
|---|---|---|
| 등 아래 **공처럼 빽빽이 뭉침** | **시끄럽게 삑삑** | **춥다** |
| **가장자리로 흩어져 등을 피함** | **조용함** + 헐떡임 | **덥다** |
| 한쪽 구석으로 몰림 | — | 외풍 |
| **고르게 퍼짐** | 부드럽게 짹짹 | **적정** |

> **조용하면 덥고, 시끄러우면 춥다.** 직관과 반대라서 학습 이벤트로 최적. 화면에 온도 숫자를 띄우지 않고 **병아리의 모습과 소리만으로** 알려줄 수 있다.

### 2-3. 물과 먹이 — 위험의 실제 시간

| 항목 | 수치 |
|---|---|
| 성계 1일 음수량 | **500ml** / **산란한 날은 2.2배** |
| 무급수 한계 | **평온 48시간, 더우면 24시간, 추우면 72시간** |
| 24시간 무급수 | 산란·소화 기능 즉시 손상 |
| 완전 무급수 후 | **산란 2주간 중단** |
| 갓 부화 병아리 | 난황낭 덕에 **72시간**은 버팀. 이후 폐사율 급상승 |
| 간식 상한 | **총 사료의 10%** (90/10 규칙) |
| grit(모래) | 사료 외의 것을 먹는 순간부터 필수. 없으면 **소낭 막힘** |

> **"물 > 사료"의 우선순위**를 아이들이 체득하게 하는 것이 목표. 한국 문방구 병아리가 일주일도 못 살고 죽은 주요 원인이 **저체온증과 grit 미섭취**였다는 것도 그대로 쓸 수 있다.

### 2-4. 똥과 위생

| 항목 | 수치 |
|---|---|
| 배설 횟수 | **하루 12~16회** (20~30분에 한 번) |
| 하루 총량 | 마리당 **100~150g** |
| **맹장 똥**(cecal) | **하루 1~2회**. 흐물흐물, **흰 모자 없음**, 냄새 지독 — **정상이며 장 건강의 지표** |
| 암모니아 15ppm | **사람이 냄새를 감지** — 이미 조치가 필요한 상태 |
| 암모니아 25ppm | 성장·사료효율·산란 저하, 호흡기 손상 |
| 젖은 깔짚 | **콕시듐 난포낭이 수개월 생존** |

> 맹장 똥은 사육 커뮤니티에서 **가장 자주 나오는 질문**("병 걸렸나요?")이다. 게임에 별도 오브젝트로 넣고 "정상이에요"를 알려주는 소소한 학습 이벤트로.

### 2-5. 질병 — 초보자 폐사 원인 TOP 5

| 원인 | 시기 | 겉모습 | 치사 속도 |
|---|---|---|---|
| **저체온/압사** | 0~7일 | 등 아래 뭉침, 큰 울음, 떨림 | 수시간~1일 |
| **Pasty butt**(항문 막힘) | 2주 미만 | 배설물이 말라붙어 봉인 | **24~48시간** |
| **콕시듐증** | **3~6주 최고 취약** | **혈변**, 웅크림, 깃털 부풀림, 창백 | 심하면 **48시간 내 전멸** |
| **마렉병** | 6주~, 12~24주 최다 | **다리·날개 마비** | 치료법 없음 (부화 24h 내 백신만) |
| **탈수** | 전 시기 | 무기력, 눈 감김 | 더위 24h / 평온 48h |

**병든 닭의 겉모습** (게임 스프라이트 체크리스트, 이른 신호 순)
① 깃털 부풀리고 웅크림 → ② 눈 반쯤/완전히 감고 머리를 날개에 파묻음 → ③ 무리에서 이탈 → ④ **볏이 창백** → ⑤ 식욕 상실 → ⑥ 설사/혈변, 산란 급감

> **닭은 포식 대상이라 아픔을 숨긴다.** 겉으로 보일 땐 이미 24~48시간 진행된 상태다.
> 게임에서 **증상 아이콘 = 이미 늦음**으로 설계하면 "매일 관찰"의 가치를 가르칠 수 있다.
>
> 전체 병아리 폐사의 **80%가 첫 7일에 집중**된다. 초반 7일을 최대 난이도 구간으로.

### 2-6. 사회 — 서열이 눈에 보이는 순간

| 항목 | 값 |
|---|---|
| 서열 형성 | 부화 후 1주 시작 → **16일부터 결정 싸움** → 6~10주 완성 |
| 개체 인식 한계 | **약 30마리** |
| 인식 단서 | **볏, 색깔, 머리·목** |
| **홰(지붕·횃대) 높이** | **우위 개체가 더 높은 단**. 같은 단에서는 **최하위가 양쪽 끝** |
| 수탉 울음 | **항상 1위부터, 서열 내림차순**. 1위를 없애면 2위가 즉시 첫 울음 |
| 수탉 울음 시각 | **일출 2시간 전** — 해를 보고 우는 게 아니라 **해가 뜰 것을 알고 미리** 운다 |
| 경보음 | **공중 = 웅크림 / 지상 = 꼿꼿이 서서 경계** — 두 자세가 완전히 다름 |
| 관객 효과 | 수탉은 **들어줄 암탉이 있을 때** 경보를 더 많이 냄 |

**싸움 시퀀스**: 눈 마주침 → 무심한 척 원 그리며 돌기 → **목 깃털(hackle)을 부채처럼 세움** → 키를 최대로 세움 → 쪼기·차기

**놀이(10주면 사라진다)**
- **까불며 뛰기(frolicking)**: 목적 없는 폭발적 질주 + 퍼덕임 + 급회전. **10주 이후 거의 사라짐**
- **물고 달아나기(worm running)**: 한 마리가 먹이를 물고 달리면 **전원이 추격**. 중간에 뺏기면 소유자 변경
- 겨루기(sparring): 가슴 부딪치며 뛰어오름, 상해 없음

> **"물고 달아나기"는 지금 벌레 시스템을 그대로 확장하면 된다.** 이 한 장면이 "닭을 키우는 느낌"을 완성한다.
> **frolicking이 10주에 사라지게** 하면 "우리 애가 다 컸구나"를 행동으로 체감시킬 수 있다.

**전염(contagion)** — 반경 안 이웃에게 같은 욕구를 전파
| 행동 | 강도 |
|---|---|
| 질주 / 놀람 | **매우 강** (정서 전염) |
| 모래 목욕 | 강 (단, 참여자 많을수록 각자 시간 ↓) |
| egg song(산란가) | 강 (알을 안 낳은 닭도 따라 부름) |
| 깃털 다듬기·앉아 쉬기·채식 | 중 |
| 수탉 울음 | 강 (**반드시 서열 내림차순**) |

### 2-7. 어미와 새끼

| 시점 | 사건 |
|---|---|
| 부화 하루 전 | **알 속 배아와 어미가 소리를 주고받음.** 알끼리도 서로 부화를 가속 |
| 1~3일 | **각인 민감기** — 어미의 꼬꼬 소리가 '닭 모양'에 각인 |
| 8일 | 병아리가 **자기 어미를 개별 식별** |
| 10~12일 | 어미 곁에 바짝 붙어 다님 |
| 12~16주 | **어미가 먼저 분리를 시작** (젖떼기) |

**어미의 먹이 가르치기**: 씨앗을 집어 **병아리 발치에 떨어뜨려 준다.** 먹이가 나오면 **평소보다 높은 음의 특별한 꼬꼬 소리**를 낸다. 먹으면 안 될 것을 노리면 **머리를 톡 쳐서 제지**한다.

### 2-8. 부화 — 21일, 그리고 "휴식 구간"

| 단계 | 시점 | 보이는가 |
|---|---|---|
| 내부 천공 | 19~20일 | 안 보임 (알에 귀 대면 삑삑) |
| **외부 천공(pip)** | 직후 | **작은 구멍 하나** |
| **휴식(rest)** | pip 이후 **몇 시간** | **정지** — 남은 노른자 흡수·혈관 폐쇄 중 |
| **껍질 돌려 깨기(zip)** | — | 가장 극적인 구간 |
| 탈출 | — | 뚜껑을 밀어 열고 나옴 |

**부화 직후 3단계** (반드시 다르게 그릴 것)
```
0~30분   젖어 있고 축 늘어짐. 거의 안 움직임 → "죽은 줄 알았다"가 정상 반응
1~3시간  솜털이 마르며 갈라져 부풀어 오름. 비틀거리며 일어서려다 자꾸 넘어짐
3~6시간  완전히 보송한 공 모양. 갑자기 대단히 활발해짐. 난치(부리 끝 돌기)가 떨어짐
```
> **"휴식 구간"을 반드시 넣어야 한다.** pip 후 아무 일도 일어나지 않는 그 정적이 긴장감을 만든다.
> 그리고 **플레이어가 껍질을 까 주려 하면 "아직 혈관이 살아 있어요" 경고** — 교육적으로도 정확하다.
> *(현재 v0.3의 부화 연출은 이미 pip→zip→열림을 구현했다. 휴식 구간과 젖은 병아리 3단계만 추가하면 완성.)*

### 2-9. 산란

| 항목 | 값 |

| 결과 패턴 | **매일 조금씩 늦게 낳다가, 너무 늦어지면 하루 건너뛰고 리셋** |
| 시간대 | **아침~정오 집중** |
| **submissive squat** | 손을 뻗었을 때 납작 웅크림 = **첫 산란 임박 신호** |
| 산란 전 | **알 1개당 평균 21.3회 둥지를 들락날락** |

### 결정 ① 닭은 죽는가

조사 결과 **네 가지 대안**이 나왔습니다. 발달심리 근거가 결정적입니다.

**결정적 변수**: 한 학급 안에 **최근 실제로 반려동물이나 가족을 잃은 아이가 있을 확률**이 상당하다. 교사가 통제할 수 없는 시점에 시스템이 죽음을 트리거하면 그 아이에게는 준비되지 않은 재노출이 된다. **이것이 실물 사육과 결정적으로 다른 지점** — 실물은 교사가 시기를 관리할 수 있다.

| 대안 | 내용 | 교육 효과 | 위험 |
|---|---|---|---|
| **A. 죽음 없음** | 시무룩 → 아픔 → 산란 중단. 한 번 돌보면 즉시 회복 | 정서적 안전, 인과가 명료 | **Neopets 함정** — "먹일 이유가 없는 시스템"이 됨 |

| **D. 은퇴·졸업** | 수명이 다하면 **"넓은 농장으로 은퇴"** + 명예의 전당 | 학년말 이별과 리듬이 일치 | 상실의 무게가 약함 |

**✅ 제 제안 — 네 개를 조합**
```
기본값(모든 학급)       : B — 완화된 이별 (되돌릴 수 있음)

```
**이유**: 다마고치가 증명한 것은 "죽음이 애착을 만든다"가 아니라 **"내 돌봄이 결과를 바꾸는 인과성이 애착을 만든다"**이다. B는 인과성을 100% 보존하면서 영구 상실만 제거한다.
그리고 **교사가 트리거 시점을 통제할 수 있어야 한다.** C를 기본값으로 두면 통제 못 하는 순간에 상실이 발생하고, 그 한 번으로 학급 전체가 앱을 끈다.

### 4-1. 시간 압축 — 1 "돌본 날" = 실제 3일 ✅승인

| 단계 | 필요한 돌본 날 | 실제 대응 | 누적 | 등교 주수 |
|---|---|---|---|---|
| 알 | **7** | 21일 (정확) | 7 | 1.4주 |
| 병아리 | **14** | 42일 = 6주 (정확) | 21 | 4.2주 |
| 어린닭 | **28** | 84일 = 12주 | 49 | **9.8주** |
| → **첫 산란** | | 누적 147일 ≈ **21주** (실제 20~24주와 일치) | | |
| 성계(산란기) | **40** | 120일 = 4개월 | 89 | 17.8주 |
| 노년 | **20** | 60일 | **109** | 21.8주 |

**"돌본 날"의 정의**: 그날 **먹고 + 마셨으면** 1일. 알은 **품어졌으면** 1일. 안 챙긴 날은 세지 않는다(멈춤).

**학기 리듬 (주 5일 등교, 한 학기 ≈ 90 수업일)**
```
1학기 시작   알을 받는다
 +1.4주      부화
 +4.2주      어린닭
 +9.8주      암탉/수탉이 된다  ← 학기의 절반
 이후 40일   산란기 — 학기 끝까지 알을 낳는다
2학기        노년 → 이별 → 다음 세대
```
→ **"1학기에 닭 한 마리를 알에서 어른까지 키운다"**가 정확히 성립한다.

> ⚠️ **현재 버그**: 돌본 날 기록이 런타임 객체(`b._care`)에만 있어 **앱을 껐다 켜면 "오늘 먹었음" 플래그가 날아간다.** 먹이고 껐다 켜서 물을 주면 그날이 돌본 날로 안 잡힘. 저장 데이터로 옮겨야 함.

### 4-2. 온도 시스템 (신규)

```
필요 온도 = 35 − 2.8 × (병아리 돌본 날)     ← 1일 = 1주령
보온등 실제 온도 = 설정 출력 × (1 − 거리/유효반경)
```

| 체감 | 조건 | 병아리 행동 |
|---|---|---|
| 춥다 | 실제 < 필요 − 2℃ | **등 아래 빽빽이 뭉침 + 시끄럽게 삑삑** |
| 적정 | ±2℃ | 고르게 퍼져 돌아다님, 부드럽게 짹짹 |
| 덥다 | 실제 > 필요 + 2℃ | **가장자리로 흩어짐 + 헐떡임 + 조용함** |

- **화면에 숫자를 띄우지 않는다.** 보온등 다이얼(약/중/강)과 높이만 조절할 수 있고, 판단은 병아리를 보고 한다.
- 3일 이상 "춥다" 지속 → 저체온 상태 → (결정①에 따라) 이별 경고
- 보온등 선택: **적외선 램프 250W**(싸지만 전기료 12배 + 화재 이벤트 확률) vs **브루더 플레이트 20W**(비싸지만 안전 + 무점등이라 수면 리듬 정상)

| **서열** | 수탉 > 암탉 > 어린닭 > 병아리 (+대장 성격). **지붕·횃대 높이 = 서열**, 같은 단에서 최하위가 양쪽 끝 |
| **수탉 울음** | **아침에 1위부터 서열 내림차순 연쇄.** 1위가 없으면 2위가 첫 울음 |
| **경보** | 공중=웅크림 / 지상=꼿꼿이. **암탉이 볼 때 더 자주** 낸다 |
| **전염** | arousal 값을 반경 내 가중 평균으로 확산 → 한 마리 놀라면 우르르 |
| **어미** | 먹이를 **병아리 발치에 떨어뜨림** + 높은 음의 특별한 꼬꼬 소리. 12~16주에 **어미가 먼저 젖뗌** |
| **놀이** | 물고 달아나기(전원 추격, 소유자 변경), 겨루기, frolicking |
| **egg song** | 산란 직후. **알을 안 낳은 닭도 따라 부름** |

### 4-9. 데스크톱 펫으로서의 예의 (Calm Technology)

| 규칙 | 근거 |
|---|---|
| **커서·클릭·키 입력을 절대 가로채지 않는다** | Goose의 치명적 실수 |
