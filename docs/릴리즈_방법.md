# 새 버전 내보내기 (릴리즈)

**어느 컴퓨터에서:** 맥북 (이 저장소가 있는 곳). 보통은 Claude에게 "릴리즈 해줘"라고 하면 아래를 대신 실행합니다.
직접 할 때는 아래 순서대로.

## 원리

윈도우 설치 파일(.exe)은 맥에서 직접 만들지 않습니다.
`v0.1.1` 같은 **태그**를 GitHub에 올리면, GitHub Actions(GitHub의 무료 빌드 컴퓨터)가
윈도우용 exe와 맥용 dmg를 만들어 **Releases** 페이지에 자동으로 올립니다. 5~10분 걸립니다.

## 순서

터미널 열기: Spotlight(⌘+Space) → `터미널` 입력 → Enter

```bash
cd /Users/kain/Kain_Brain/game/TeacherPet
```
→ 티처펫 폴더로 이동. 아무 출력도 없으면 정상.

```bash
npm version patch
```
→ `package.json`의 버전을 0.1.0 → 0.1.1 처럼 하나 올리고, 커밋과 태그를 자동으로 만듭니다.
정상이면 `v0.1.1` 한 줄이 출력됩니다.
(기능이 크게 바뀌었으면 `patch` 대신 `minor` → 0.2.0)

```bash
git push --follow-tags
```
→ 코드와 태그를 GitHub에 올립니다. 이 순간 빌드가 시작됩니다.
정상이면 마지막 줄에 `* [new tag] v0.1.1 -> v0.1.1` 이 보입니다.

## 끝났는지 확인

1. 크롬에서 https://github.com/Kang-T/teacherpet/actions 를 엽니다.
2. 맨 위 줄이 노란 점(진행 중) → 초록 체크(완료)로 바뀌면 끝. 빨간 X면 실패 — 그 줄을 눌러 로그를 Claude에게 보여 주세요.
3. https://github.com/Kang-T/teacherpet/releases 에 새 버전과 exe·dmg 파일이 보이면 성공입니다.

## 흔한 오류

- `npm version` 에서 `Git working directory not clean` → 저장 안 된 변경이 있음. 먼저 `git add -A` 후 `git commit -m "메시지"`.
- 푸시할 때 로그인 창 → GitHub 계정(Kang-T)으로 로그인. `gh auth login` 이 되어 있으면 안 뜹니다.
