## 2. 내부 상태

### 2-1. 욕구 (Needs) — 0~100, 시간이 지나면 저절로 변한다
| 욕구 | 오르는 조건 | 내리는 조건 | 낮/높을 때 행동 |
|---|---|---|---|
| **배고픔** hunger(배부름으로 표시) | 먹기(+35), 벌레(+8) | 시간(8시간에 100) | 낮음 → 모이통 탐색, 🌾, 성장 정지 |
| **목마름** thirst | 마시기(+40) | 시간(6시간) | 낮음 → 물통, 💧 |
| **에너지** energy | 자기(분당 +6), 앉기(+1) | 깨어 있는 시간(10시간에 100), 달리기 2배 | 낮음 → 하품·앉기·닭장에서 잠. 수업 중엔 자기 쉬움 |
| **심심함** boredom | 가만히 있으면 상승(3시간에 100) | 놀이(추격·날개짓·벌레·쓰다듬기·친구 놀이) | 높음 → 놀이 행동, 장난, 친구 찾기 |
| **외로움** social | 혼자 있을 때(4시간에 100) | 친구 2유닛 안(빠르게 감소), 어미 근처 | 높음 → 친구·어미 곁으로 |
| **청결** clean | 모래 목욕(+55), 깃털 다듬기(+7) | 시간(시간당 -4) | 40 미만 → 깃털이 칙칙해짐, 모래밭을 찾아감 |
| **긴장** stress | 때찌(+40), 수탉 울음(새끼 +25), 떨어짐(+15), 낯선 커서 접근(겁쟁이) | 시간(15분에 -50), 어미 곁(빠름) | 높음 → 도망·경계·먹지 않음 |

### 2-2. 기분 (Mood) — 욕구·관계에서 계산되는 파생값
- **쾌·불쾌 valence** (-1~1): `+친밀도 +행복 -배고픔결핍 -목마름결핍 -긴장`
- **각성 arousal** (0~1): `에너지×0.5 + 심심함결핍… + 긴장`
- **졸림 sleepy**: `1 - 에너지/100`
- 기분은 **표정**(눈꺼풀·눈썹·볼·부리)과 **걸음걸이·속도**로 드러난다. 이모지는 사건 알림에만 쓴다.

### 2-3. 관계 (Relations)
- **친밀도 aff** (선생님과, 0~100): 쓰다듬기·벌레·부르면 오기·배고플 때 먹이 → ↑ / 때찌·굶김·억지로 들기 → ↓
  - 70↑ 좋아함: 아침에 달려와 반김, 커서 졸졸, 부르면 즉시, 쓰다듬으면 오래 가만히
  - 30↓ 서먹함: 커서 피함(💨), 불러도 무시(😒), 들면 버둥
- **어미-새끼 각인 momId**: 부화시킨 암탉. 병아리는 어미 3유닛 안을 좋아하고, 어미는 새끼를 자주 바라보고 곁에 와서 부리로 다듬어 준다(nuzzle). 새끼가 자면 곁에서 품는다.
- **서열 rank**: 수탉 > 암탉 > 어린닭 > 병아리 (+대장 성격 보정). 모이통에서 높은 서열이 오면 낮은 쪽이 비켜선다.
- **친구**: 같은 단계끼리 놀이 상대(어린닭 추격놀이).

## 3. 성격 (Personality) — 20종, 태어날 때 랜덤

## 4. 행동 선택 — 효용 기반 (Utility AI)

매 결정 시점(행동이 끝났을 때, 또는 사건 발생 시)마다 후보 행동의 점수를 계산해 가장 높은 것을 고른다. 약간의 무작위성(소프트맥스)으로 예측 불가능하게.

| 행동 | 점수 (0~) | 조건 |
|---|---|---|
| 먹기 | (100-배부름)/100 × appetite × 모이있음 | 모이통 잔량 ≥ 1끼 |
| 마시기 | (100-물)/100 × 1.1 | 물통 잔량 |
| 자기 | 졸림² × sleepy × (수업이면 ×1.5) | — |
| 놀이(친구 쫓기·날개짓·달리기) | 심심함/100 × playful × 에너지/100 | 긴장 낮음 |
| 친구/어미 곁 | 외로움/100 × sociable (+새끼면 ×1.5) | 친구 존재 |
| 커서 다가가기 | 친밀도/100 × approach × curiosity × 커서 최근 움직임 | 커서 가까움 |
| 커서 피하기 | (100-친밀도)/100 × flee × 커서 가까움 | 친밀도 < 40 |
| 산책 | 0.25 × curiosity × energy | — |
| 깃털 다듬기 | 0.15 × tidy | — |
| 가만히 | 0.2 | — |
| 특수(쪼기·날개·울음·품기) | 단계별 기본 0.2 | — |

**사건 반응 (즉시, 효용 무시)**: 벌레 등장 → 추격(긴장 낮고 배부름 < 95이면) / 부름 → 이동(고집이면 확률 무시) / 때찌 → 놀람+도망 / 수탉 울음 → 새끼 놀람 / 서열 높은 닭 접근(모이통) → 비킴 / 떨어짐 → 착지 + 긴장.

## 5. 표정 (Expression) — 기분에서 자동
| 요소 | 규칙 |
|---|---|
| 눈꺼풀 | 졸림↑ → 반쯤 감김 / 쾌↑ → 아래에서 올라오는 미소 눈(초승달) |
| 눈썹 | 긴장·불쾌 → 안쪽이 내려감(화남) / 슬픔(배고픔·외로움) → 안쪽 올라감 |
| 볼 홍조 | 쾌·친밀도에 비례 |
| 부리 | 말할 때·울 때·먹을 때만 벌어짐 |
| 자세 | 불쾌 → 고개 숙임·날개 처짐 / 각성↑ → 몸 세움·빠른 걸음 |

## 6. 닭끼리 (Social)
- **어미 돌봄**: 어미는 30초에 한 번 새끼를 바라보고, 새끼가 3유닛 밖이면 다가가 부리로 다듬는다(❤️). 새끼가 자면 옆에서 앉아 품는다.
- **각인 따르기**: 병아리는 어미가 5유닛 이상 멀어지면 종종 따라간다.
- **수탉 울음**: 8유닛 안 병아리·어린닭은 긴장 +25 → 폴짝 놀라 반대쪽으로 2~4유닛. 암탉은 무시. 대담한 성격은 안 놀람.
- **놀이**: 어린닭·병아리 둘이 6초간 추격놀이(한쪽이 쫓고, 한쪽이 도망), 끝나면 둘 다 심심함 -40.
- **서열**: 모이통 1.2유닛 안에서 높은 서열이 오면 낮은 쪽은 😣 하고 물러난다. (대장 성격은 안 물러남)
- **깨우기 장난**: 개구쟁이가 자는 친구 옆에서 날개짓 → 친구 깨서 잠깐 쫓아감.

## 7. 학급 시간과의 연결
- **수업**: 모두 앉음, 자기 쉬움, 놀이·울음 없음, 커서 반응 최소.
- **쉬는 시간**: 놀이 ×2, 수탉 울음 1회, 에너지 소모 ↑.
- **아침 첫 실행**: 수탉 울음(있으면), 친밀도 70↑ 닭은 달려와 반김, 벌레 3마리 배급.
- **하루 마감(종료)**: 위치·욕구 저장. 자리 비운 시간만큼 배고픔·목마름 감소(최대 40), 에너지는 회복.

## 6-2. 부상 (2026-09-16)

높은 곳에서 떨어지면 다친다. 병아리·어린닭은 낙하속도 6.5, 어른은 8.5를 넘으면.
- 🤕 아이콘, 건강 −25(어린 것) / −12(어른), 긴장 +25
- **절뚝임**: 한쪽 다리를 끌고 몸이 기운다. 이동 속도 45%. 뛰지 않고 놀지 않는다
- 어미가 있으면 달려와 다독인다
- **하루를 잘 돌보면(먹이+물) 낫는다** → 💚

## 7-2. 1단계에서 들어간 생태 행동 (2026-09-16)

| 행동 | 구현 | 고증 |
|---|---|---|
| **땅 긁기 scratch** | **새 기본 자세.** 쫀다 → 쫀 자리로 올라선다 → 오른발·왼발 교대로 뒤로 긁는다 → **뒤로 물러선다** → 고개 45° 기울여 확인. 긁으며 조금씩 전진 | 활동 시간의 34%, 쪼기 60%. 후진은 발밑이 가려지기 때문. 첫 긁기는 오른발 |
| **머리 hold–thrust** | 걷는 동안 머리를 공간의 한 점에 정지시켰다가 탄도처럼 앞으로 내던진다 | 닭의 눈은 눈구멍에 고정 — 머리로 시야를 안정시킨다 |
| **모래밭 dustpit** | 얕게 파인 모래 구덩이 소품. 깨끗함이 40 밑으로 떨어지면 **모래밭까지 걸어가서** 목욕한다 | 닭은 자기가 구덩이를 판다 |
| **모래 목욕 dustbath** | 5단계(자리 파기 → 부리로 흙 긁어모으기 → 날개 떨어 먼지 튕기기 → 옆으로 누워 문지르기 → 일어나 털기), 먼지 파티클 3회, **이틀에 한 번**, 반경 5 안에 **전염**, **붐비면 35% 짧아짐**, 끝나면 깃털 다듬기. 방해받으면 **rebound(나중에 더 하고 싶어짐)** | Vestergaard 1982. 평균 27분·이틀 간격·사회적 동조·밀도 효과·박탈 후 반동 모두 실측 |
| **햇볕 쬐기 sunbathe** | 옆으로 누워 한쪽 날개를 활짝 펼침, 눈 반쯤 감음. **끝나면 반드시 깃털 다듬기** | 옆구리 피부에 볕을 직접 쬐어 D3 생성 + 기생충 제거. 다듬기로 섭취 |
| **스트레칭 stretch** | 같은 쪽 날개와 다리를 동시에 뒤로 | 닭 특유의 편안함 행동 |
| **물고 달아나기 worm running** | 벌레에 먼저 닿은 닭이 **물고 도망**, 나머지 전원 추격, 0.75유닛 안에서 **45% 확률로 빼앗김**, 3.5~7.5초 뒤 또는 구석에 몰리면 먹음 | Kruijt 1964. 닭의 3대 놀이 중 하나 |
| **까불며 뛰기 frolic** | 목적 없는 폭발적 질주 + 급격한 방향 전환 + 점프. **병아리·어린닭만** | 10주 이후 사라진다 → 성장을 행동으로 체감시킴 |
| **서열별 홰 자리 roostSlot** | 지붕에 오를 때 **1위가 용마루 한가운데, 아래 서열은 양쪽 끝**으로 | 우위 개체가 더 높은 단, 최하위가 양 끝 |
| **서열 연쇄 울음 crowChain** | 아침·쉬는시간에 **1위부터 1.6초 간격으로 내림차순**. 혼자 울어도 아래 서열이 이어 운다 | 1위 제거 시 2위가 즉시 첫 울음 — 실험으로 확인된 사실 |
| **submissive squat** | 첫 산란 4일 전부터 납작 웅크림 + 🥚 | 산란 임박의 실제 신호 |

## 7-3. 단계별 고유 행동 · 무리 · 경보 (2026-09-16)

### 단계마다 다르게 행동한다
| 단계 | 고유 행동 | 가중치 차이 |
|---|---|---|
| **병아리** | **뭉치기(huddle)** — 가장 가까운 또래에게 붙어 앉는다. 춥거나 놀랐을 때 강해진다. 또래가 없으면 보온등 아래로. **짧고 잦은 쪼기** | 긁기 짧게(2~4초) · 잠 1.8배 · 모래목욕 0.45배 · 어미 따라다니기 최강 |
| **어린닭** | **날개 연습(flap)** 아주 자주 + 이어서 점프. **겨루기(spar)** — 또래와 마주 보고 가슴을 부딪치며 뛰어오른다 ⚔️ | 긁기 3~6초 · 모래목욕 0.8배 |
| **암탉** | 산란·품기. **둥지 들여다보기**. 가장 오래 긁는다 | 긁기 5~10초 · 모래목욕 1.3배 |
| **수탉** | **파수(guard)** — 무리가 먹는 동안 자기는 먹지 않고 목을 빼고 좌우를 훑는다. **먹이 부르기(tidbit)** — 먹이를 집었다 떨어뜨리며 울어 암탉들을 불러 모은다 | 긁기 짧게 · 서열 연쇄 울음 |

### 무리 (flocking)
- 산책 목적지가 **무리 중심 쪽으로 끌린다.** 멀어질수록 강하게 (`sociable` 비례)
- 무리에서 7유닛 이상 떨어지면 **외로움이 2.5배 빨리 쌓이고**, `regroup` 행동으로 돌아간다 👀

### 경보 (alarm) — 겁 많음
| 종류 | 자세 | 발생 |
|---|---|---|
| **공중 aerial** | **납작 웅크리고 하늘을 올려다본다** | 커서가 위에서 빠르게 내려올 때 |
| **지상 ground** | **목을 길게 빼고 꼿꼿이 서서 좌우를 훑는다** | 커서가 옆으로 빠르게 지나갈 때, 때찌 |

- **대담한 성격은 안 놀란다** (`bold` 비례로 확률 감소). 겁쟁이는 더 크게 놀라고 더 멀리 도망

## 7-4. 2단계 — 돌봄의 현실 (2026-09-16)

### 온도 (`sim/health.js`)
```
필요 온도 = 35℃ − 1.2℃ × (병아리 돌본 날)      ← 실제 "주당 2.8℃"를 돌본 날(3일) 단위로 환산
자리 온도 = 21℃(실온) + 15℃ × 보온등 출력 × (1 − 거리/4.5)^1.6
```
**화면에 숫자를 띄우지 않는다.** 보온등 다이얼(끔/약/중/강)만 있고, 판단은 병아리를 보고 한다.

| 돌본 날 | 필요 | 강 | 중 | 약 | 끔 |
|---|---|---|---|---|---|
| 0 | 35.0℃ | ✅ 36 | 🥶 31 | 🥶 26 | 🥶 21 |
| 3 | 31.4℃ | 🥵 36 | ✅ 31 | 🥶 26 | 🥶 21 |
| 7 | 26.6℃ | 🥵 | 🥵 | ✅ 26 | 🥶 21 |
| 11~14 | 21.8→21℃ | 🥵 | 🥵 | 🥵 | ✅ 21 |

| 상태 | 병아리가 하는 행동 |
|---|---|
| **춥다** | 등 아래로 달려가 **빽빽이 뭉치고 시끄럽게 삑삑** 🥶 |
| **적정** | 고르게 퍼져 돌아다닌다 |
| **덥다** | 등에서 **멀리 흩어져 날개를 벌리고 부리를 열어 헐떡인다** 🥵 (조용함) |

### 배설물 · 암모니아 (`sim/hygiene.js`)
- 마리당 하루 2~3개(실제 12~16회를 압축). **12%는 맹장 똥** — 흐물흐물하고 **흰 모자가 없다**. 정상이지만 냄새가 지독하다
- 암모니아 = 배설물 수 × 시간 × 깔짚 상태. **15ppm 냄새 / 25ppm 성장·산란 정지**
- 안 치우면: **1일 5ppm → 2일 19ppm(냄새) → 3일 40ppm(정지)**
- 청소: **클릭하거나 드래그해서 쓸어담기** + 🔦 남은 곳 보기(PowerWash 방식)
- 깔짚: 7일이면 갈아야 한다. 갈면 암모니아가 65% 줄어든다

### 질병 (`sim/health.js`) — 초보자 폐사 원인 4종
| 병 | 원인 | 증상 | 치료 |
|---|---|---|---|
| 🥶 **저체온** | 추운 상태 6시간 누적 | 깃털 부풀림·웅크림 | 온도를 맞춰 하루 |
| 💧 **항문 막힘** | 온도를 벗어난 병아리 | 〃 | **닭을 클릭해 닦아 주기** |
| 🩸 **콕시듐증** | 암모니아 25ppm↑·젖은 깔짚. **어린 것이 1.8배 취약** | 〃 | **약 구입 → 물에 타기** |
| 🚫 **소낭 막힘** | 그릿 없이 간식 3회↑ | 〃 | 하루 사료 끊기 |

**공통 증상**: 깃털을 부풀려 몸이 커 보이고, 웅크리고, 눈을 반쯤 감고, **볏이 창백해지고**, 거의 움직이지 않는다.
닭은 아픔을 숨기므로 **증상이 보일 땐 이미 진행된 상태다.** 아픈 동안은 자라지 않는다. (죽지는 않는다 — 기획서 결정 ①-B)

### 사료 3단계
| 사료 | 단백질 | 맞는 단계 |
|---|---|---|
| 스타터 | 18~20% | 병아리 |
| 그로워 | 15~18% | 어린닭 |
| 레이어 | 16~18% + **칼슘 3~4%** | 암탉·수탉 |

## 8-2. 좌표 전수조사 (2026-09-18)

마당을 화면에서 떼어내고 깊게(32×30) 만든 뒤, **거리를 좌우(x)로만 재던 코드**가
연달아 문제를 일으켰다. 하나씩 발견하는 대신 한 번에 훑었다.

### 그동안 이 원인으로 나온 증상
| 증상 | 원인 |
|---|---|
| 닭이 보온등으로 순간이동 | `goTo` 가 x 목표만 받아, 도착 순간 z 를 툭 바꿈 |
| 벌레를 앞뒤로 못 쫓음 | 쫓기 거리가 `|Δx|` — 바로 앞이면 거리 0 으로 '도착' 판정 |
| 커서가 멀어도 놀람 | 놀람 반경이 `|Δx|` — 저 뒤쪽도 같은 x 면 놀람 |
| 켜도 계속 추움 | `tempAt` 이 `|Δx|` — 램프 뒤 20칸도 따뜻하다고 나옴 |
| 소품이 맨 앞으로 끌려옴 | 드래그 z 를 `-3.2~2.2`(얕던 시절)로 클램프 |
| 벌레가 마당 밖에 놓임 | 벌레 z 를 1.2 고정 (마당 앞끝은 0.6) |
| 달릴 때 고개가 반대로 굳음 | 진행 방향을 '걷기'에만 넣고 '쫓기'에서 누락 |

### 고친 방식
- 공용 거리 함수 `gap2(a, c)` · `gapTo(b, x, z)` 를 두고 **20곳**을 옮겼다.
- `flockCenter()` 가 `{x, z}` 를 돌려준다. `lure` 에도 z 를 넣었다.
- `goTo(b, x, anim, z)` — 앞뒤 목표까지 받고, 두 축을 함께 나아간다.
- 진행 방향은 이동 코드마다 넣지 않고,
  **그리기 직전에 '지난 프레임 대비 실제로 움직인 방향'** 에서 한 번에 구한다.
  이동 경로가 무엇이든(걷기·쫓기·달아나기·까불기·밀려남) 자동으로 반영된다.

### 남겨둔 것 (의도적)
- `near(a, c, r)` — x 와 z 를 각각 보는 상자 판정. 그대로 둔다.
- `gopeek` 의 `|lure.x - b.x|` — 거리 판정이 아니라 **걸음 폭** 계산.
- `panic` 의 좌우 도주 — 옆으로 내빼는 동작이라 z 가 필요 없다.

### 교훈
좌표계를 바꿀 때는 **그 좌표를 읽는 모든 곳**을 한 번에 훑어야 한다.
눈에 띄는 것만 고치면, 남은 것들이 며칠에 걸쳐 하나씩 튀어나온다.

## 8-4. 배경 — 카메라가 정한 한계 (2026-09-19)

마당 밖 풍경을 만들면서 **카메라 때문에 못 하는 일**이 하나 드러났다. 적어 둔다,
모르면 또 같은 걸 만들어 놓고 안 보인다고 헤매게 된다.

**하늘은 화면에 들어오지 않는다.** 시야각이 22°(위아래 ±11°)인데 내려다보는 각이 16~55°다.
화면 맨 위조차 수평선보다 5° 아래를 본다. 그래서 3D 로 구름을 띄우면 아무리 높이,
아무리 멀리 둬도 화면 밖(위)이다. 실제로 만들어 띄워 보고 알았다.

- 화면 위쪽의 '하늘'은 **아주 멀어서 하늘색이 된 땅**이다. 안개(`THREE.Fog`)가 만든다.
- 그래서 안개 색과 CSS 하늘의 아래쪽 색이 **같아야** 경계가 안 보인다.
- 구름은 캔버스 **위**에 얹는다(`#clouds`, z-index 4). 그 자리가 하늘 노릇을 하기 때문이다.

**보이는 거리에 한계가 있다.** 기본 시점(24°)에서 땅은 `z ≈ -117` 까지만 화면에 든다.
안개는 카메라에서 `D×1.8` 까지 먹는다(`D` 는 카메라 거리, 확대하면 가까워지므로 `fit()` 에서 다시 잡는다).
처음에 언덕을 `z = -180` 에 뒀다가 영영 안 보였다. 지금 층은 이렇다.

| 층 | z |
|---|---|
| 마당 | 0.6 ~ -30 |
| 가까운 나무·덤불 | -10 ~ -45 |
| 밭 | -48 ~ -68 |
| 먼 나무 | -52 ~ -70 |
| 언덕 | -72 ~ -95 |

**세로로 긴 화면에서는 아래가 빈다.** 마당은 32×30 인데 24° 로 내려다보면 화면에서 납작해진다.
가로는 꽉 차는데 세로는 2배 넘게 남는다. 그 여백이 위로는 풍경, 아래로는 빈 풀밭이 됐다.
그래서 울타리 앞에 길·덤불·들꽃을 놓아 '마당으로 들어오는 길'로 만들었다.

**멀리 있는 것에 입체를 주면 하얘진다.** 밭 이랑을 높이 0.1 의 상자로 만들었더니
빛을 받아 흰 바코드처럼 보였다. 안개까지 먹으니 더 하얘졌다. 이랑은 **납작한 색 띠**로 바꿨다.

**바닥재는 울타리 안만 바꾼다.** 온 세상을 함께 바꿨더니 흙마당을 고른 순간
이웃 밭도 언덕도 흙이 됐다.

**아이들이 실제로 받는 그 빌드(`web/`)를 헤드리스 크롬으로 연다.** 창은 뜨지 않는다.

| 농장 코드를 만들고 다시 읽는다 | 6단계. 이름·단계·성격·돌본 날이 그대로 돌아오는가 |
| 한 글자만 틀려도 걸러낸다 | 잘못 옮겨 적은 코드를 조용히 받아들이면 엉뚱한 닭이 생긴다 |
| 자리가 빠진 저장도 숫자 자리를 얻는다 | x 가 없는 저장을 읽으면 NaN 자리에 서서 영영 안 보이던 문제 |
| 자리가 망가진 저장도 고쳐 읽는다 | 같은 문제 (null·NaN 까지) |
| 성격과 단계도 함께 따라온다 | 이름만 보면 성격이 조용히 사라져도 모른다 |
| QR 판 크기·모서리 표식·시간줄·검은 칸 | 규격에서 값이 정해진 자리. 틀리면 어떤 사진기도 못 읽는다 |
| QR 마스크가 실제로 다르게 나온다 | 8가지를 재 보고 고르는 과정이 죽어 있지 않은지 |
| 새로 시작이 저장을 먼저 멈춘다 | `__tpWipe` 가 없으면 지운 농장이 3초 뒤 되살아난다 |
| 같은 날 같은 반이면 늘 같은 날씨 | 서버가 없으니 이 약속이 깨지면 기능 자체가 무의미해진다 |
| 반이 다르면 날씨가 갈린다 / 넉 달이면 6가지가 다 나온다 | 시드가 한쪽으로 쏠리지 않는지 |
| 날씨가 날마다 굳지 않고 바뀐다 / 나흘 넘게 안 이어진다 | 같은 날씨가 계속되면 아이가 금세 흥미를 잃는다 |
| 학급 코드는 숫자만 남는다 | 아이가 쓰는 칸이다. 이름이 들어가면 안 된다 |
| 날씨에 따라 마당 온도가 달라진다 | 추운 날 병아리가 보온등을 찾는 근거 |
| 자랑 글에 반·학교가 들어가지 않는다 | 이 앱은 '아무것도 보내지 않는다'로 서 있다 |
| **꾸며도 닭의 수치가 그대로다** | 8단계의 약속. 깨지면 '잘 돌봤는가'가 기준이 아니게 된다 |
| 산 것이 실제로 입혀진다 / 장식물이 마당에 놓인다 | 돈만 나가고 안 바뀌는 일이 없도록 |
| 코인이 줄어든다 / 가진 것을 다시 눌러도 안 나간다 / 돈이 모자라면 못 산다 | 값 계산 |
| 모자를 다시 누르면 벗는다 | 벗을 길이 없으면 아이가 갇힌다 |
| 소품 자리는 farm 에 마당 좌표로 남는다 / 화면에도 반영된다 | 8단계 속 공사 |
| 배경을 올려도 프레임이 버틴다 | 학교 크롬북에서 돌아가야 한다 (중간 24ms 미만) |
| 드로우콜이 예산 안에 있다 | 풍경을 늘리다 보면 조용히 무거워진다 (480개 이하) |

### 쓰는 법
- 파일: `scripts/check.js`(실행기) · `scripts/checks.probe.js`(검사 본체)
- 렌더러 쪽 훅은 `window.__tpTest` (app.js 끝)
- **새 버그를 만나면 고치기 전에 여기에 항목을 먼저 더한다.**
  그래야 같은 버그가 다시 나오지 않는다.
- `main` 에 올리면 GitHub Actions 가 리눅스에서도 돌린다(`.github/workflows/check.yml`).
  배포는 막지 않는다 — 화면 검사는 이따금 불안정할 수 있어 알려만 준다.

### QR 은 바깥 해독기로 따로 검증했다
QR 이 '규격대로 생겼는가'와 '사진기가 실제로 읽는가'는 다른 이야기다.
만들면서 실제로 두 번 틀렸는데, 둘 다 그림만 봐서는 멀쩡해 보였다.

1. 형식 자리를 비우다가 시간줄 두 칸 `(6,8)`·`(8,6)` 을 같이 지웠다.
2. 형식 비트를 아래 자리부터 놓았다. 위 자리부터가 맞다.

그래서 임시 폴더에서 `jsqr`(읽는 쪽)과 `qrcode`(믿을 만한 만드는 쪽)를 받아
**판 1~20 × 마스크 8종, 180가지를 전부 만들어 다시 읽어** 확인했다.
두 꾸러미는 저장소에 넣지 않았다 — 앱은 지금도 바깥 것을 하나도 쓰지 않는다.
QR 을 손보면 그 검증을 다시 한 번 돌리는 것이 맞다.

### 페이지에서 난 오류도 함께 본다
검사 항목과 별개로, 도는 동안 페이지에서 난 예외를 모아 마지막 항목으로 판정한다.
예전에 실제로 있었던 버그(환영 카드를 갈아 끼운 뒤 없어진 `#wbStart` 를 붙잡다 터진 것)를
일부러 되살려 보면 이 항목이 잡는다 — 그때는 아무도 못 잡고 사용자가 찾았다.

### 이 장치가 못 잡는 곳
검사는 한 대의 크롬에서, 한 가지 화면 크기(900×1200)로만 돈다.
휴대폰 크기·다른 브라우저(사파리)·느린 기기는 여전히 직접 봐야 한다.
서비스 워커가 **두 번째 방문에** 옛 코드를 주는 문제도 여기서는 안 잡힌다 —
매번 깨끗한 프로필로 처음 방문만 하기 때문이다.
