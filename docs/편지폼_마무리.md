# 할머니께 보내는 편지 — 구글 폼 마무리 (맥북에서, 40초)

제가 폼 파일까지는 만들었습니다. 도구에 Forms API가 없어서 **문항 추가와 전체 공개**만 못 했습니다.

**폼 편집 주소**
https://docs.google.com/forms/d/1gsmnBJDLLRoVmIBY_TgTPYKzOba2izJqSI-cUDyzeUM/edit

---

## 1) 문항 넣기

위 주소를 열면 "제목 없는 질문"이 하나 있습니다. 그걸 이렇게 바꿉니다.

**질문 1** — 오른쪽 드롭다운에서 **「장문형」** 선택
```
할머니께 하고 싶은 말
```
그 아래 '설명' 칸(⋮ → 설명)에 붙여넣기:
```
고치고 싶은 것, 있었으면 하는 것, 이상한 것 무엇이든 좋아요.
이름이나 학교는 적지 않아도 됩니다.
```

**질문 2 (있으면 좋음)** — `+` 눌러 추가, **「객관식」**
```
무엇에 대한 이야기인가요?
```
선택지 4개:
```
고쳤으면 하는 것
있었으면 하는 것
이상해요 / 잘 안 돼요
그냥 하고 싶은 말
```

## 2) ⚠️ 가장 중요 — 이메일을 모으지 않도록

오른쪽 위 **⚙️ 설정** → **응답** 에서
- **「이메일 주소 수집」을 `수집 안 함`** 으로 (기본이 그렇지만 꼭 확인)
- **「로그인 필요」 / 「응답 1회로 제한」 을 끕니다**

이걸 안 끄면 학생이 학교 구글 계정으로 로그인해야 하고,
**그 순간 학생 이메일이 수집되어 "개인정보를 모으지 않습니다"가 거짓이 됩니다.**

## 3) 보내기 주소 복사

오른쪽 위 **[보내기]** → 🔗 (링크) 탭 → **[URL 단축] 체크** → 복사

## 4) 저에게 주세요

복사한 주소를 그냥 붙여넣어 주시면 제가 코드에 넣고 배포하겠습니다.
(`src/renderer/core/config.js` 의 `LETTER_FORM` 한 줄입니다.)

---

## 확인하는 법

주소를 복사해서 **시크릿 창에 붙여넣어 보세요.**
로그인 화면 없이 바로 폼이 뜨면 성공입니다.
로그인을 요구하면 2번을 다시 보셔야 합니다.

## 처리방침에도 반영합니다

폼 주소를 받으면 개인정보 처리방침에 이 문장을 추가하겠습니다.

> **편지를 보낼 때** — [할머니께 편지 쓰기]를 누르면 구글 폼이 **새 창**으로 열립니다.
> 거기 쓴 내용은 구글을 거쳐 만든 사람에게 갑니다. 티처펫 자체는 아무것도 보내지 않습니다.
> 이름·학교를 적지 않아도 되고, 적지 않기를 권합니다.
