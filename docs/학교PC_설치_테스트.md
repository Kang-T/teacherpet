# 학교 윈도우 PC에서 티처펫 설치·테스트하기

**어느 컴퓨터에서:** 학교 윈도우 PC (터미널·명령어 필요 없음. 마우스만으로 됩니다.)

## 1. 설치 파일 내려받기

1. 크롬(또는 엣지)을 열고 주소창에 아래 주소를 입력합니다.
   ```
   https://github.com/Kang-T/teacherpet/releases/latest
   ```
2. 페이지 아래쪽 **Assets** 목록에서 `TeacherPet-0.1.0-win-x64.exe` (숫자는 버전에 따라 다름)를 클릭합니다.
3. 크롬이 "이 파일은 일반적으로 다운로드되지 않습니다" 같은 경고를 띄우면
   → 다운로드 목록에서 파일 옆 **∧ (더보기)** → **"계속"** 또는 **"위험을 감수하고 다운로드"** 를 누릅니다.
   (서명이 없는 새 프로그램이라 뜨는 경고입니다.)

## 2. 설치하기

1. 내려받은 exe 파일을 더블클릭합니다.
2. **파란 창 "Windows의 PC 보호"** 가 뜨면:
   - 창 안의 작은 글씨 **"추가 정보"** 를 클릭
   - 그러면 아래에 **"실행"** 버튼이 새로 생깁니다 → 클릭
3. 설치 마법사가 뜹니다. **다음 → 다음 → 설치 → 마침**.
   - "현재 사용자만" / "모든 사용자" 를 물으면 **현재 사용자만** (관리자 비밀번호 없이 됩니다).
4. 바탕화면에 **티처펫** 아이콘이 생기면 성공입니다.

**흔한 문제**
- "이 앱은 관리자가 차단했습니다" → 학교 PC 보안 정책입니다. 정보부/전산 담당 선생님께 설치 허용을 요청해야 합니다.
- 설치 창이 아예 안 뜨고 조용함 → 백신이 격리했을 수 있습니다. 백신 알림 창을 확인해 "허용"으로 바꿉니다.

## 3. 켜 보기

1. 바탕화면 **티처펫** 아이콘을 더블클릭합니다.
2. 화면 아래 가운데에 **입양 창**이 뜹니다. 병아리·햄스터·거북이·토끼 중 하나를 클릭합니다.
3. 바탕화면 맨 아래에 **알**이 나타나면 정상입니다.
4. 작업 표시줄 오른쪽 아래 **∧** 를 눌러 **병아리 아이콘**이 있는지 확인합니다. 여기가 티처펫 메뉴입니다.

## 4. 테스트 체크리스트 (되는지 하나씩 확인)

- [ ] 알을 클릭하면 "(꿈틀)" 말풍선이 뜬다
- [ ] 메뉴 → 펫 탭 → **품어주기** 3번 (30분 간격 제한이 있어서 하루에 걸쳐 확인) → 부화한다
- [ ] 펫이 바탕화면 아래를 걸어다닌다
- [ ] 펫이 **없는 곳**을 클릭하면 바탕화면 아이콘·다른 프로그램이 평소처럼 눌린다 (클릭 통과)
- [ ] 펫을 드래그해서 옮길 수 있다
- [ ] 트레이 아이콘 오른쪽 클릭 → **수업 시작** → 오른쪽 아래 빨간 타이머가 뜨고 펫이 앉는다
- [ ] 타이머 정지 → 펫이 다시 돌아다닌다
- [ ] 뽑기 탭에 이름 넣고 뽑기 → 결과가 나온다
- [ ] 설정 → 크기 **크게** → 전자칠판에서 보기 좋은 크기가 된다
- [ ] 트레이 → **종료** → 펫이 사라진다
- [ ] 다시 켜면 펫·이름·설정이 그대로 남아 있다

안 되는 항목이 있으면 **어느 항목이 어떻게 안 되는지** + 가능하면 **화면 사진**을 남겨 주세요.

## 5. 지우기

윈도우 설정 → 앱 → 설치된 앱 → **티처펫** → 제거.
(펫 데이터는 `C:\Users\사용자이름\AppData\Roaming\티처펫\state.json` 에 남습니다. 완전히 지우려면 이 폴더도 삭제.)
