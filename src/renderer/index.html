🌡️ 온도 챌린지 결과

🧑‍🏫 선생님용 — 함께 생각해 볼 질문과 예상 답
  1. 병아리가 보온등 아래로 뭉쳤을 때는 어떤 상태였을까요?
    → 추운 상태입니다. 모여서 서로의 체온으로 몸을 데우려고 합니다.
  2. 더워졌을 때 병아리는 어떻게 행동했나요? 그때 보온등은 어떻게 해야 했나요?
    → 가장자리로 흩어지고 헐떡입니다. 보온등 세기를 낮춥니다.
  3. 병아리가 자랄수록 필요한 온도가 낮아지는 까닭은?
    → 솜털이 깃털로 바뀌어 스스로 체온을 지킬 수 있게 되기 때문입니다.
  4. 어미닭이 있으면 보온등이 왜 필요 없을까요?
    → 병아리가 어미 날개 밑에서 체온을 나눠 받기 때문입니다.
